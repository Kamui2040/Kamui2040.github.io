# K2040 Projects

The public website for K2040, with an introduction, project overview, a short blog and a directory of official links.

## Structure

- index.html — landing page and current announcements
- about/ — introduction and blog posts
- links/ — verified profiles and support links
- news/ — current announcements
- relaunch.css, relaunch.js, relaunch-copy.js — shared responsive visual system and five locales
- about/posts.json — editable blog content
- relaunch-site-news.js — generated announcement feed
- relaunch-destinations.json — verified link directory

The public pages are generated by python3 tools/build_site.py. The generator validates blog content, locale completeness and link host restrictions.

## Validate

node --test tests/relaunch.test.cjs

Firefox-specific layout checks: python3 tools/qa_browser.py <temporary-output-directory> and python3 tools/qa_narrow.py <temporary-output-directory>.

The website uses only the new approved branding. Older release/news feeds are deliberately disconnected. New posts from other rebuilt project sites may be connected after their own public releases.
