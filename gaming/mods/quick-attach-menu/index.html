Release history

Selected historical release notes (English). See the official mod page for current releases.

  1. 0.5.222

    Restored the Quick Attach Builder shortcut in MCM. Fixed the Quick Attach page display with MCM Categorizer. Fixed Hunting Rifle attachment swaps, improved category navigation and ordering, kept clipped items in view, and added optional movement and mouse-look while the Quick Attach Menu is open.

  2. 0.5.220

    Fixed keybind synchronization between Settings and MCM, including reset and clearing controls. MCM now handles keybind changes and persistence directly. Fixed Mouse 4/5 recognition, modifier combinations, invalid keycodes and duplicate MCM entries. Improved Proton and PrismaUI keybind handling, JSON handling and keybind registry validation. Generated menus prioritize OMOD display names over loose-mod item names, while preserving custom names and ECO-authored labels. Improved compatibility without native MCM.

  3. 0.5.219

    Fixed MCM hotkeys showing None or reverting after assignment; default shortcuts initialize correctly on fresh installations. Fixed the Pip-Boy opening when closing Quick Menu or Menu Builder using their keyboard shortcuts. Improved shortcut handling when closing or switching menus, preserving custom keybindings.

  4. 0.5.216

    Fixed RIS rail attachment compatibility when another installed OMOD supplies the required weapon-target keyword; dynamic keywords remain subject to active OMOD and live-instance evidence. Added controller shortcuts, movement and confirmation in Quick Menu layouts, plus navigation in Builder and Settings. Text editing and drag-based reordering still use keyboard or mouse. Unified K2040 Mods MCM includes shared parent and child configuration, hotkeys and settings; native MCM is optional. Added experimental Cheat mode, disabled by default, to bypass loose OMOD inventory requirements while retaining attachment and weapon validation and transaction safeguards.

  5. 0.5.213

    Added controller navigation in Quick Menu, Builder and Settings, using thumbsticks or D-pad. Attachments are applied only on confirmation. Improved navigation across all four layouts, corrected reversed Compact Hybrid controls, and improved dropdowns, sliders and confirmation dialogs. Added controller shortcut options and radial wheel pagination. Fixed an Anniversary Edition crash caused by an incompatible weapon refresh function; added automatic re-equipping after closing the menu, improved default material handling, hid internal configuration slots and improved generated attachment compatibility checks. Improved keyboard, mouse and controller behavior. Fallout 4 AE 1.11.240 remained beta; the visual refresh could reset loaded ammunition. Fallout 4 1.10.163 retained its original refresh method.

  6. 0.5.199

    Fixed safe installation into restored attachment points, including the reported SREP M203 barrel-to-muzzle path.

  7. 0.5.198

    Fixed Tactical Reload compatibility causing false attachment swap safety errors. Improved internal/provider OMOD handling and attachment dependency ordering. Added a per-weapon Force Unsafe Swaps option for unsupported or unusual setups; safe swapping remains enabled by default.

  8. 0.5.197

    Added persistent diagnostic logging controls and menu slowdown from 0% to 100%, including normal speed, slow motion and full pause. Fixed hidden categories and attachments reappearing after changes in Cascade view, restricted mouse movement in Quick Menu, Builder and Settings, and cursor handling when switching between Builder and Settings.

  9. 0.5.192

    Addressed the attachment bug and prevented menu hotkeys from opening the menus during dialogue.

  10. 0.5.181

    Fixed generated attachment compatibility so unrelated weapon mods no longer appear. Builder shows compatible player-facing attachments, while Quick Menu shows installed and carried options. Fixed false unsafe-to-replace errors, Prisma Dock registration and filtering of internal helper OMODs.

  11. 0.5.180

    Initial release: change compatible weapon attachments from an in-game quick menu using ECO-authored or runtime-generated menus. Four layouts: Cascade, Radial Wheel, Compact Hybrid and Horizontal Bar. Configure per-weapon visibility, order, labels, bracket handling and menu source through Builder. Customize keybindings, scale, position, opacity, themes, colors, hints and behavior in Settings. Export and import per-weapon profiles. Validated provider/child ordering, inventory checks, post-change verification and rollback for supported attachment operations.

For the latest downloads, compatibility, installation instructions and credits, see the official mod page.
