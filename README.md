# K2040 Projects

This repository contains the public K2040 project website.

## Project pages

- Main page: <https://kamui2040.github.io/>
- Android Projects: <https://kamui2040.github.io/K2040-Android-Releases/>
- Gaming Mods: <https://kamui2040.github.io/K2040-Gaming-Mods/>

The site brings released K2040 projects, downloads, documentation, and updates together in one place. It supports English, German, Portuguese (Portugal), Spanish, and French, as well as light and dark themes.

## Gaming Mods

The Gaming Mods section lists released public mods and tools. Each project page provides a short overview, current download links, release notes, and screenshots where available.

Official project or release pages remain the source of truth for downloads and version information.

## Updating the site

Keep public wording short, natural, and easy to understand. Add technical detail only when it is needed to explain a tool, solve a problem, or help with installation or troubleshooting.

Only verified public project information should be shown on the site.
