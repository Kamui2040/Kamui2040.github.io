# K2040 Website contributor rules

This is the single public website repository for K2040, including its gaming, Android and fiction sections. Extend the current shared implementation with newly built sections; do not restore legacy site layouts, code, styles or feeds. Product source repositories and official distribution platforms remain authoritative for release facts and downloads. Keep it lightweight, responsive, accessible, and aligned with the approved K2040 design system. The owner-approved wordmark and angular frames are authoritative visual assets.

Public source may include only owner-approved writing, licensed/provenanced media, source code, tests, reproducible inputs and necessary public documentation. Do not include private creative work, secrets, personal data, private operations, unreleased project details or private archival changelogs.

Gaming is a distinct website under /gaming/, with its own primary navigation and landing page. Shared website switching, language, themes and central News connect the active sites. Keep authoritative downloads on their official platforms.

Use tools/build_site.py to generate shared HTML pages; keep the five locales and browser routes consistent. Only show verified profile/download links. Keep current News distinct from historical release records, and never import old project feeds.

Before accepting changes, run source, link, localization, navigation, responsive and accessibility checks as relevant. Preserve the public release identity and keep old data out of the new site.

## Fiction publication boundary

Only explicitly released fiction, approved illustrations and verified edition links belong in the public catalogue. Preserve separate complete language editions, semantic chapter/block IDs, illustrations, and back matter. Do not copy private source metadata, unreleased lore, or prototype geography. Reader and Lexicon use one visibility model; gate entry existence, summaries, details, relationships, search and curated contextual links before rendering. Reader progress and bookmarks are semantic, not rendered page numbers. Validate complete pagination and spoiler visibility before publication.

Preserve the physical page-turn animation in paged Reader layouts, with left/right page and adjacent-space navigation. Ignore text selections, contextual Lexicon terms and other controls; keep continuous reading and reduced-motion preferences free of page-turn animation. Validate the animation and navigation in a real browser before accepting Reader changes.
