Based on fireeyeeian’s original Windows mod, this native Linux port provides configurable movement, combat, equipment, loot, zombie behavior, field of view, weather and time-of-day adjustments. Flatpak and AppImage packages are available from the official mod page. It requires the Linux version of Dead Island Riptide Definitive Edition.
